[Heading 2] BR-LMS-001 — Course-specific access control
--- TABLE ---
Rule Type | Authorization
Rule Statement | A user may access a course workspace only for a course in which the user is enrolled, assigned, or otherwise linked.
Applies To | UC-LMS-001, 004, 006, 009
Condition / Trigger | Course access requested
Required Outcome / Constraint | Allow only if course-specific association is established.
Exceptions / Exclusions | Observer linkage granularity remains unresolved.
Source / Rationale | PS §3.1
Related CFRs | 
Status | Active
--- END TABLE ---
