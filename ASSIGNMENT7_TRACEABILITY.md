The source RTM lists all 75 AFRs but has blank UC mapping, BR mapping, WF mapping, transition row, minimum representation, and coverage cells for every AFR. Its summary nevertheless reports “AFR Full coverage count 75” and “PASS.” This defect is recorded rather than silently attributed to the source.

“Missing” means no IAA-specific implementation is present on the `main` base used for this branch. Shared Fusion authentication, permission checks, module registry, and shell are reusable foundations, not evidence that an IAA requirement is implemented. Implementation paths and tests below are targets until the code exists.
