# Patent Management System (PMS) — Requirements Traceability Matrix (RTM)

Governing Method: Problem Statement (PS) -> CFR/AFR -> Use Cases (UC) + Business Rules (BR) -> Basis/Composite Workflows (BW/CW) -> Code/Tests

## 1. Summary of Scope Baseline
- Historical Atomic Functional Requirements: 203 active obligations (PMS-AFR-010 to PMS-AFR-220)
- Consolidated Requirements (CFR): CFR-PMS-001 to CFR-PMS-024+
- Actor-Triggered Use Cases: 33 Use Cases (UC-PMS-001 to UC-PMS-033)
- Governing Business Rules: 84 Business Rules (BR-PMS-003 to BR-PMS-146)
- Basis Workflows: 16 Workflows (BW-PMS-01 to BW-PMS-16)
- Composite Workflows: 5 Workflows (CW-PMS-01 to CW-PMS-05)
