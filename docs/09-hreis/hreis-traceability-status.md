## Known boundaries that still need evidence or external configuration

- Exact numeric leave entitlements and institutional authority matrices are
  not specified by the problem statement. The app requires effective policies
  and manually verified opening credits, and refuses to assume values.
- Actual payroll/finance status exchange is not proven just by manually
  recording an Accountant's external reference; the corresponding institutional
  integration remains an external dependency.
- Verified document-byte upload and storage are not provided by the existing
  core file service (its storage is explicitly read-only); manual evidence
  references are not equivalent to verified stored attachments.
- Official SMTP/provider configuration, trusted recipient-role resolution,
  and monitored worker operation need environment evidence.
- Student 2's independent FR/UC/BR/WF test suites are required separately.
