## Reproduce

With Ollama running and the installed model available, from the repository root:

```sh
python3 devtools/qwen_elm_trial.py generate docs/08-delivery/elm-qwen-trial/jobs/02h-queries-small.json
```

This appends a new prompt/response record and rewrites `modules/leave_elm/services/queries.py`. It does not rewrite the job JSON. Results need not be identical. Saved `responses/*.request.json` contains exact request configurations. [README.md](README.md) describes the build harness and log files.
