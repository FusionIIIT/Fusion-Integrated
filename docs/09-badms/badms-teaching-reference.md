## Workflows

The archive, storage-extension, and restoration workflow transitions are defined centrally in [`domain/transitions.py`](../../modules/badms/domain/transitions.py). Their state tables and role boundaries are described in [`state-machine.md`](state-machine.md). HTTP endpoints are enumerated in [`api/urls.py`](../../modules/badms/api/urls.py).

## Scope notes

IAM role permission mapping and the `BA-UC-019` permission-administration API are implemented in the separately approved `Fusion_System_Administrator` checkout. No parallel BADMS RBAC tables are created. The BADMS role administration UI is deferred by user decision. Actual retention durations and production S3/KMS resources remain institute/deployment inputs; the implementation does not invent them.
