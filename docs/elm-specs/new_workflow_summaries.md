# Employee Leave Management (ELM) Workflow Summaries

## Workflow: New CL/RH - No Substitute Gate (BW-EL-01)
- **Purpose:** Process a valid CL/RH application that does not require substitute consent.
- **Key Steps:**
  1. Employee submits a valid CL/RH request.
  2. Unit Head reviews and approves or rejects the request.

## Workflow: New CL/RH - Substitute Accepted (No Loop) (BW-EL-02)
- **Purpose:** Process a valid CL/RH application requiring substitute coverage through accepted substitute consent.
- **Key Steps:**
  1. Employee submits a valid CL/RH request.
  2. Substitute responds to the request.
  3. Unit Head reviews and approves or rejects the request.

## Workflow: New CL/RH - Substitute Declined, Replacement Accepted (One Loop Traversal) (BW-EL-03)
- **Purpose:** Process a valid CL/RH application through one substitute-decline recovery traversal and replacement acceptance.
- **Key Steps:**
  1. Employee submits a valid CL/RH request.
  2. Substitute declines the request.
  3. Employee nominates a replacement substitute.
  4. Substitute responds to the request.
  5. Unit Head reviews and approves or rejects the request.

## Workflow: New Higher-Sanction Leave - No Substitute Gate (BW-EL-04)

## Composite Workflow: New Leave Processing and Pending Withdrawal (CW-EL-01)
- **Purpose:** Provide the end-to-end progression for a new leave request, including substitute consent/recovery, Unit-Head-final CL/RH decisions, higher-sanction routing, the Director-specific self-sanction route, and immediate withdrawal.
- **Key Steps:**
  1. Employee submits a valid new leave request.
  2. Substitute responds to the request if required.
  3. Unit Head reviews and approves or rejects the request.
  4. Higher-sanction routing if applicable.
  5. Director makes the final sanction decision if applicable.
  6. Immediate withdrawal if requested.
