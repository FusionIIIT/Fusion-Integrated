BR-GYM-001 — Valid Student Leadership

Rule ID

BR-GYM-001

Rule Name

Valid Student Leadership

Rule Type

Validation

Rule Statement

Club coordinator, co-coordinator, and replacement leaders must reference valid students.

Applies To

Club creation; leadership change

Condition / Trigger

Whenever a student leadership assignment is made

Required Outcome / Constraint

Reject/stop the operation if the selected leader is not a valid student.

Exceptions / Exclusions

None defined

Source / Rationale

Corrected PS + prior BR001 + accepted baseline
