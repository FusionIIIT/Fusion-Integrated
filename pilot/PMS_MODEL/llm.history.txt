USER # PMS problem statement (read-only spec)
USER 
USER 2.1 Overview
USER The Patent Management System (PMS) digitizes and streamlines institutional patent application management and intellectual property protection within Fusion ERP.
USER The module supports application submission, application documentation, review and decision workflows, revision and resubmission, attorney assignment, legal and patentability assessment, budget approval and financial tracking, external patent-office filing support, post-grant tracking, maintenance fee tracking, office-action response tracking, withdrawal, co-inventor and agreement management, prior-art search support, document version management, patent licensing and technology-transfer request tracking, appeal handling, deadline management, notifications, audit trails, and reporting.
USER PMS is intended to improve correctness, transparency, compliance support, timely communication, auditability, and operational coordination while reducing manual effort.
USER PMS records and tracks patent-management information. Legal decisions, patent-office decisions, actual payment execution, external accounting operations, and external patent-office processing remain outside PMS unless explicitly recorded, validated, notified, routed, logged, or reported within PMS.
USER 2.2 Actors
USER 2.2.1 Applicant
USER Submits new patent applications with required documentation.
USER Tracks application status and progress.
USER Revises and resubmits applications based on feedback.
USER Manages co-inventor information and agreements.
USER Conducts prior-art searches through PMS-supported search functions.
USER Withdraws applications when withdrawal is allowed by current application status.
USER Responds to office actions with attorney support.
USER Views personal application reports.
USER 2.2.2 Director
USER Reviews assigned patent applications for technical merit.
USER Approves, rejects, or requests revisions to applications.
USER Provides detailed justification for decisions.
USER Reviews and approves budgets for patent filing and prosecution costs.
USER Makes final decisions on patent maintenance and renewal.
USER Views reports, dashboards, and analytics available within PMS.
USER Has oversight over application workflow in the Director domain.
USER 2.2.3 PCC_ADMIN
USER Assigns applications to Directors based on explicit assignment criteria.
USER Assigns attorneys from approved panels, subject to stated exceptions.
USER Coordinates PMS operations and monitors workflow.
USER Resolves or routes conflict-of-interest and exceptional cases within PMS scope.
USER Manages PMS-specific configuration and role assignments.
USER Generates system-wide PMS reports.
USER Maintains attorney panels and expertise mappings.
USER 2.2.4 Attorney
USER Conducts legal and patentability assessment.
USER Performs prior-art searches in relevant databases through PMS-supported search functions.
USER Provides legal opinions on patent applications.
USER Prepares applications for external filing.
USER Files applications with patent offices and records filing details in PMS.
USER Responds to office actions.
USER Manages post-grant tracking and maintenance-fee reminders/deadline tracking.
USER Provides legal advice throughout the patent lifecycle.
USER 2.3 Functional Scope
USER 2.3.1 Application Submission and Management
USER Applicants submit patent applications with required fields: title, abstract, detailed description, claims, inventor information, and supporting documents.
USER PMS validates that required application fields are complete before accepting submission.
USER PMS validates uploaded documents as PDF format, under 50 MB, and malware-free.
USER PMS classifies documents by sensitivity.
USER PMS assigns a unique application ID to each accepted application and sets the application status to Submitted.
USER Inventor agreements must be completed before filing.
USER PMS records application history and notifies relevant stakeholders.
USER 2.3.2 Application Assignment and Routing
USER After submission, PCC_ADMIN or PMS automatic routing assigns applications to Directors.
USER Assignment uses Director expertise matching, workload balance, and conflict-of-interest checks.
USER Directors or PCC_ADMIN cannot review applications where they are listed as inventors.
USER PMS updates the application status to Under Review upon assignment.
USER PMS notifies the assigned Director and initiates the applicable review timeline.
USER 2.3.3 Application Review and Decision
USER Directors review application details, documents, and supporting materials.
USER Directors must decide Approve, Reject, or Needs Revision.
USER Directors must provide detailed justification of at least 50 characters for all decisions.
USER Director review must be completed within 15 business days of assignment.
USER If an application is rejected or requires revision, PMS sends detailed feedback to the Applicant.
USER Approved applications proceed to attorney assignment.
USER PMS maintains an audit trail of the review process.
USER 2.3.4 Application Revision and Resubmission
USER Applicants may revise applications with status Needs Revision or Rejected.
USER Applicants must resubmit revised applications within the applicable 60-day resubmission period from the relevant rejection/revision decision date.
USER PMS validates that a revision addresses Director feedback.
USER PMS maintains version control for revised applications and starts a new review cycle after resubmission.
USER If the resubmission deadline expires, PMS changes the application status to Expired.
USER Applicants may withdraw applications before the filing stage where current status allows withdrawal.
USER 2.3.5 Attorney Assignment
USER Only PCC_ADMIN can assign attorneys to approved applications.
USER Attorneys must be selected from an approved panel unless an institutional exception is recorded or allowed.
USER Attorney assignment considers attorney expertise, workload, conflict-of-interest checks, and Applicant preference when the preferred attorney is in the approved panel.
USER The assigned Attorney must accept or decline the assignment.
USER PMS updates application status to Attorney Assigned or Pending Review as applicable.
USER 2.3.6 Patentability Assessment and Legal Review
USER Attorney conducts legal and patentability analysis.
USER Attorney performs prior-art search in relevant databases.
USER Attorney evaluates novelty, non-obviousness, and utility.
USER Attorney records a detailed patentability opinion with recommendation: File Patent, Do Not File, or Needs Amendment.
USER PMS records the opinion and notifies relevant stakeholders.
USER Attorney may request additional information or extensions as supported by PMS.
USER 2.3.7 Budget Approval and Financial Tracking
USER Director reviews and approves costs for patent filing and prosecution.
USER Budget information includes filing fees, attorney fees, and administrative costs.
USER If total cost exceeds the configured threshold limit, PMS routes/escalates the case to the applicable higher authority.
USER Budget approval is allowed only for applications with status Approved.
USER PMS validates budget availability before approval where budget availability information is available to PMS.
USER PMS logs financial transaction records and authorization levels for audit purposes.
USER Accounting, payment execution, and external finance-system processing are outside PMS unless recorded or integrated as PMS data.
USER 2.3.8 External Filing and Patent Office Communication
USER Attorney prepares the application package according to applicable patent-office requirements.
USER PMS validates format compliance with applicable patent-office standards where validation rules are available to PMS.
USER Attorney submits the application to the Indian Patent Office or an international patent office.
USER International filings require additional justification to be recorded in PMS.
USER PMS captures external filing ID, filing date, and confirmation information.
USER PMS updates application status to Filed after filing is recorded.
USER PMS logs official communications with patent offices.
USER 2.3.9 Post-Grant Tracking and Maintenance
USER Post-grant tracking activates only for patents with status Granted.
USER PMS calculates maintenance-fee schedules based on grant date and jurisdiction where the applicable schedule rules are available to PMS.
USER Attorney manages maintenance-fee reminders and deadline tracking in PMS.
USER Before each maintenance deadline, an explicit renewal decision is required.
USER Attorney seeks renewal decision from the Director.
USER Director decides Renew or Do Not Renew.
USER If renewal is approved, Attorney processes the maintenance action and records the transaction/status in PMS.
USER PMS maintains renewal history and schedules the next maintenance cycle.
USER 2.3.10 Office Actions and Responses
USER PMS records office actions received from patent offices.
USER Attorney reviews office actions and prepares draft responses.
USER Applicant reviews and approves a response when the applicable process requires Applicant review.
USER Attorney finalizes and submits responses within applicable deadlines.
USER Attorney files extension requests when additional time is needed and the process allows extension.
USER PMS tracks response submission and updates status.
USER PMS automates timeline and deadline tracking for office-action responses where applicable deadline data is available.
USER 2.3.11 Application Withdrawal
USER Applicants may withdraw applications before the filing stage.
USER PMS validates that withdrawal is allowed based on current application status.
USER Applicant must provide a withdrawal reason.
USER PMS records co-inventor consent when the applicable process requires consent.
USER PMS updates application status to Withdrawn and removes the application from the active queue.
USER PMS maintains withdrawal history.
USER 2.3.12 Co-Inventor and Agreement Management
USER Applicants manage multiple inventors and ownership shares.
USER PMS validates inventor information and ownership percentages.
USER PMS collects and validates inventor consent and electronic signatures where legally permitted and configured.
USER Inventor agreements must be completed before filing.
USER PMS sends notifications to affected parties when inventor information changes.
USER 2.3.13 Prior Art Search
USER Applicants and Attorneys can search for prior-art references through PMS-supported search facilities.
USER PMS queries relevant patent and publication databases where integrations or search access are available.
USER PMS displays search results with relevance ranking.
USER Users can attach selected references to an application.
USER PMS logs search sessions for audit trail.
USER PMS supports keyword optimization and classification mapping as part of the search process.
USER 2.3.14 Document Version Management
USER PMS maintains version history of application documents.
USER Users can upload new document versions where their role and application status permit upload.
USER PMS applies automatic version numbering.
USER Previous document versions are archived and accessible according to role and status access rules.
USER PMS logs document modifications with user and timestamp.
USER Document access is controlled based on user role and application status.
USER Applicants can edit documents only when application status is Needs Revision.
USER 2.3.15 Patent Licensing and Technology Transfer
USER Applicants can submit licensing or technology-transfer requests.
USER PMS routes such requests to the appropriate committee or Director as stated by the applicable institutional process.
USER PMS tracks negotiation process information.
USER PMS records final agreements.
USER PMS updates or shares financial-system information where integration is available.
USER PMS maintains license records with confidentiality controls.
USER 2.3.16 Appeal Process
USER Applicants may file appeals against rejected applications.
USER Appeals must be filed within the applicable allowed time period.
USER Applicant provides grounds and justification for appeal.
USER Director reviews appeal and supporting documentation.
USER Director may Uphold Rejection, Remand for Amendment, or Modify Decision.
USER PMS records the appeal outcome and initiates the next applicable process step.
USER 2.3.17 Deadline Management and Tracking
USER PMS calculates and monitors patent-management deadlines where deadline rules are available.
USER Deadlines include review deadlines, revision deadlines, office-action response deadlines, and maintenance-fee deadlines.
USER PMS generates alerts at configurable intervals, including 30 days, 15 days, and 5 days before deadline where applicable.
USER PMS sends deadline notifications to relevant stakeholders.
USER Missed deadlines trigger escalations according to the configured escalation chain.
USER PMS logs deadline-tracking activities.
USER 2.3.18 Reports and Analytics
USER PCC_ADMIN and Directors can generate PMS reports.
USER Available reports include application status and progress reports, financial and budget reports, deadline and pending-action reports, inventor and co-inventor reports, patent portfolio analysis, and workload and assignment reports.
USER PMS supports scheduled reports, exportable reports, and customizable reports as stated in the source baseline.
USER PMS logs report access for audit purposes.
USER PMS provides dashboards, historical data analysis, trend reporting, and workload analytics within the explicitly stated PMS reporting scope.
USER 2.3.19 Notifications
USER PMS issues system-generated email notifications for application submission and status changes.
USER PMS issues notifications for assignment to Director or Attorney.
USER PMS issues notifications for review decisions: approve, reject, or revision.
USER PMS issues notifications for budget approval or rejection.
USER PMS issues notifications for filing confirmations and office actions.
USER PMS issues notifications for deadline reminders and escalations.
USER PMS issues notifications for maintenance-fee reminders.
USER PMS issues notifications for document updates and version changes.
USER PMS notification triggering is within module scope; central email delivery infrastructure is outside PMS scope.
USER 2.3.20 Audit Trail and Compliance
USER PMS maintains audit trails of PMS actions.
USER PMS logs user actions, status changes, and document modifications.
USER PMS logs include user ID, action type, timestamp, application ID, previous state, and new state where applicable.
USER Critical operations create immutable audit records.
USER Audit logs support compliance verification and forensic analysis.
USER PMS supports document sensitivity classification, role-based access control, and version control for confidential patent information.
USER PMS applies data encryption at rest and in transit where this security requirement is implemented by the platform/module boundary.
USER 2.3.21 PMS Role, Workflow, Integration, and System Boundaries
USER Exactly one active PCC_ADMIN oversees PMS.
USER Multiple Directors handle reviews based on expertise domains.
USER Multiple Attorneys from approved panels conduct legal assessments.
USER Multiple Applicants submit applications.
USER PMS supports automated routing based on configurable rules, status-driven workflow, escalation mechanisms for delayed actions, and parallel processing where explicitly applicable.
USER PMS may integrate with patent office systems, financial systems, email notification systems, and document management systems where available.
USER External systems remain outside PMS unless PMS explicitly validates, routes, records, notifies, logs, or reports based on their data or events.
USER The System is not treated as a regular primary actor in later use cases derived from this problem statement. System behavior appears as internal validation, routing, status update, deadline calculation, notification, escalation, postcondition, maintained data, or reporting behavior.
USER 2.4 Scope Boundaries
